ARCANUS KADDINGHALL v1.0 — FIRST APP FILES

This is an experimental mobile-friendly web app. Population and economy are provisional, not canon.

EASIEST PC TEST:
1. Extract the ZIP.
2. Open index.html in Chrome or Edge.
3. Use the buttons. It automatically saves to this browser.

TO INSTALL ON ANDROID:
The folder must first be hosted at an HTTPS website (for example GitHub Pages). Opening index.html as a local file on Android does not provide normal PWA installation/offline service-worker support. Once hosted, open its URL in Chrome and choose Install app or Add to Home screen if offered.

SAVE DATA:
Export Save downloads JSON; Import Save reads it. There is NO automatic PC-phone syncing yet. Keep backups.

IMPORTANT:
Browser local storage may be cleared by browser settings. The app is experimental, and the model is deliberately simplified.
